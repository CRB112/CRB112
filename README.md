# Hi, I'm Connor Banning

CS senior at Kent State University (graduating Spring 2027). I build automation and simulation software in Python and Rust, with a focus on systems that are safe to retry and honest about their limits.

## Projects

**[Email Sifting Agent](https://github.com/CRB112/Email-Agent)** · Python, Microsoft Graph, Gmail API
A desktop app that sorts Microsoft and Gmail inboxes with configurable rules. Sifts run on a background worker with cancellation and per-account checkpoints, so an interrupted run can be retried safely. Includes an offline test suite and a rule simulator that runs against fake inboxes.

**[ExitZero](https://github.com/Kent-Brogrammers/ExitZero)** · Rust, React, TypeScript, Axum
Evacuation simulator built by a 4-person team. 1st place overall at the Stark State College Halloween Hackathon. I wrote the Rust simulation engine: deterministic spawning, continuous-space navigation, collision checks, and the evacuation loop.

**[Q-Atlas](https://github.com/Kent-Brogrammers/Q-Atlas)** · Python, FastAPI, Qiskit, SvelteKit
Quantum computing project for the OSU Qiskit Fall Fest (5-person team). I wrote the compiler, which turns a restricted subset of Python into QUBO models for QAOA circuits. Submitted code is parsed and verified, never executed.

**[Rocky AI Learning Platform](https://github.com/Epsilon-Elephants/SWE-MAIN)** · Python, Streamlit, MongoDB
Homework platform for professors and students with AI grading against reference answers. I own the team's GitHub org and set up the PR workflow and CI (pytest unit and regression tests with coverage reports).
